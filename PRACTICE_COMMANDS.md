# Terminal Practice Commands

Run these one at a time in Windows Command Prompt.

```cmd
mkdir TerminalPractice
cd TerminalPractice
mkdir Projects
mkdir Notes
type nul > hello.txt
dir
cd Projects
type nul > project.txt
cd ..
cd Notes
type nul > notes.txt
cd ..
dir
```

## What happened?

1. `mkdir TerminalPractice` created the main folder.
2. `cd TerminalPractice` entered the folder.
3. `mkdir Projects` created a Projects folder.
4. `mkdir Notes` created a Notes folder.
5. `type nul > hello.txt` created a file.
6. `dir` displayed the contents.
7. The remaining commands created another file and moved between folders.

Try to understand each command instead of copying everything blindly.
