# Terminal Practice Assignment

## Goal

Practice controlling a project through the terminal instead of using File Explorer for every action.

## Tasks

- [ ] Create a project directory.
- [ ] Create three subdirectories.
- [ ] Create at least three files.
- [ ] Navigate between directories using `cd`.
- [ ] Display files using `dir`.
- [ ] Initialize Git with `git init`.
- [ ] Check the repository using `git status`.
- [ ] Stage the project using `git add .`.
- [ ] Create a commit.
- [ ] Push the project to GitHub.

## Reflection

After completing the exercise, write 3–5 sentences answering:

1. What did you learn?
2. Which command was easiest?
3. Which command was confusing?
4. How can terminal skills help you as an IT student?
